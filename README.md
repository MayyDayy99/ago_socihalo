# Nexus

Személyes szociális háló térképezés és vizualizáció.
Egy felhasználós web app. Sötét felület. Sötét adatok.

## Helyi fejlesztés

```bash
pnpm install
cp .env.example .env.local   # töltsd ki a Supabase értékekkel
pnpm dev
```

## Deploy

Push to `main` → GitHub Actions builds and deploys to Pages.

## Stack

React · TypeScript · Vite · Tailwind · D3 · Supabase · GitHub Pages.
